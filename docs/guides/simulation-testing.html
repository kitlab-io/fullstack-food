Testing the simulated sites

Fullstack Food: test the simulation scenarios

A simulated site behaves like a real one: simulated nodes report readings, the hub controls them, and the dashboard shows it. This guide walks you through breaking things on purpose and checking that the system notices, says so clearly, and recovers. Tick each step as you go; your progress is kept in this browser.

Everything here runs against simulated nodes. Passing these scenarios says the control logic and the dashboard work; it says nothing about real hardware, which has not been tested yet.
